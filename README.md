# WBCONV_REQ_P — WebClass 課題・教材ダウンローダー

> 名城大学の学習管理システム **WebClass** に自動ログインし、  
> 全授業の課題・教材 PDF を一括ダウンロードするコマンドラインツール。

## できること

| 機能 | 詳細 |
|------|------|
| 自動ログイン | 名城大学SSO（SAML認証）を通じて WebClass に自動でログイン |
| 全授業一括取得 | 履修中の全授業を自動検出してスキャン |
| 課題 PDF ダウンロード | `qstn_frame.php` 形式の課題ファイルを取得 |
| 教科書 PDF ダウンロード | `txtbk_frame.php` 形式の教科書を章ごとに取得 |
| スキップ機能 | 既にダウンロード済みのファイルは再取得しない（高速化） |
| 暗号化ログイン情報保存 | ユーザーID・パスワードを Fernet で暗号化してローカル保存 |
| リッチなターミナルUI | `rich` ライブラリによるカラフルな進捗表示 |
| ログ記録 | すべての通信ログを `log.txt` に記録 |

## 動作環境

| 項目 | 要件 |
|------|------|
| Python | **3.13.1 以上** |
| パッケージ管理 | `uv`（推奨）または `pip` |
| OS | macOS / Linux / Windows |
| ネットワーク | 名城大学のネットワーク、または VPN 接続 |

### 依存ライブラリ

```
bs4          >= 0.0.2    # HTML パース（BeautifulSoup4）
cryptography >= 46.0.7   # 認証情報の暗号化（Fernet）
requests     >= 2.33.1   # HTTP 通信
rich         >= 13.7.0   # ターミナル UI
```

## セットアップ

### 1. リポジトリをクローン

```bash
git clone <リポジトリのURL>
cd webclass_kadai_getter
```

### 2. 依存パッケージをインストール

#### uv を使う場合（推奨）

```bash
# uv がなければ先にインストール
curl -LsSf https://astral.sh/uv/install.sh | sh

# 依存パッケージをインストール
uv sync
```

#### pip を使う場合

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install bs4 cryptography requests rich
```

## 使い方

### uv で起動（推奨）

```bash
uv run main.py
```

### pip 環境で起動

```bash
python main.py
```

### 初回起動時

初回のみ、ユーザーID とパスワードの入力が求められます。

```
╭──────────────────────────────────────────╮
│ WBCONV_REQ_P                             │
│ WebClass 課題・教材ダウンローダー         │
╰──────────────────────────────────────────╯
! 初回起動: 認証情報を作成します
userid: your_student_id
password: ********
```

入力した情報は **暗号化**（Fernet）されて `userdata.txt` と `key.key` に保存されます。  
2回目以降は自動でログインします。

## ダウンロード先のフォルダ構造

ダウンロードされたファイルは `class/` フォルダ以下に、授業・コース・コンテンツ名の階層で保存されます。

```
class/
├── プログラミング演習Ⅱ/
│   ├── 第1回：変数と型/
│   │   └── 課題1/
│   │       └── work.pdf
│   └── 第2回：制御構文/
│       └── 教材/
│           ├── 第1章,導入.pdf
│           └── 第2章,基礎.pdf
└── データ構造とアルゴリズム/
    └── 教科書/
        └── 第1章,はじめに.pdf
```

## ファイル構成

```
webclass_kadai_getter/
├── main.py             # エントリーポイント。ログイン〜全授業取得を実行
├── webclass.py         # WebClass との通信・スクレイピングのコア
├── auth_token.py       # 名城大学 SSO から認証トークンを取得
├── filedownload.py     # PDF ファイルのダウンロード処理
├── settings.py         # ユーザー情報の暗号化・保存・読み込み
├── general.py          # ログ出力・リッチ UI のユーティリティ
├── key.key             # 暗号化キー（Git 管理外 / 絶対に共有しないこと）
├── userdata.txt        # 暗号化された認証情報（Git 管理外）
├── log.txt             # 通信ログ（デバッグ用）
├── pyproject.toml      # プロジェクト設定・依存関係
└── class/              # ダウンロードされたファイルの保存先
```

## 認証情報の管理

- `settings.py` は **Fernet 対称暗号**（`cryptography` ライブラリ）を使って、パスワードを `userdata.txt` に暗号化保存します。
- 暗号化キーは `key.key` に保存されます。
- **どちらのファイルも `.gitignore` に含めてください**。他人のPCに渡ったり、GitHubにアップすると認証情報が漏洩します。
- 認証情報をリセットしたい場合は `key.key` と `userdata.txt` を削除して再起動してください。

## 注意事項

- このツールは **名城大学の学生が自身のアカウントで利用する**ことを前提としています。
- 他者のアカウントでの使用や、大学のシステムへの過度な負荷は**利用規約違反**になります。
- ネットワークエラーが発生した場合は、大学のVPNに接続しているか確認してください。
- 対応しているコンテンツ形式は **課題（qstn）** と **教科書（txtbk）** のみです。それ以外は `未対応のコンテンツ` としてスキップされます。
- ダウンロード済みのファイルは自動でスキップされるため、**差分のみ取得**したい場合はそのまま再実行すれば OK です。
